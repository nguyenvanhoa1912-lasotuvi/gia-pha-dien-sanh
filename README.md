# Gia phả họ Nguyễn Diên Sanh

Trang gia phả nội tộc họ Nguyễn làng Diên Sanh (Hải Thọ, Hải Lăng, Quảng Trị).

- Dữ liệu trong `data.enc.json` được mã hóa AES-256; chỉ người có mật khẩu mới mở được.
- `keys.json` chứa khóa đã bọc bằng mật khẩu thành viên và mật khẩu quản trị (không chứa mật khẩu).
- Chỉnh sửa dữ liệu qua chế độ quản trị trên trang; không sửa tay các file trên.
